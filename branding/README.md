# Keyboard Macros OS — Brand Assets

## Concept
Geometric K-inspired mark with an execution/play wedge. SVG masters are editable vector files. The icon artwork is a first implementation of the approved concept and can be refined further.

## Palette
- Primary blue: `#2F80ED`
- Dark background / text: `#0F172A`
- Light background: `#F8FAFC`
- Secondary text: `#94A3B8` (dark background) / `#64748B` (light background)

## Files
- `svg/logo-dark-background.svg` — horizontal logo for dark surfaces
- `svg/logo-light-background.svg` — horizontal logo for light surfaces
- `svg/symbol-dark.svg`, `svg/symbol-light.svg` — standalone symbol
- `svg/app-icon-dark.svg`, `svg/app-icon-light.svg` — rounded app icon
- `svg/tray-dark.svg`, `svg/tray-light.svg` — simplified tray symbol
- `png/` — raster previews and app icon sizes
- `tray/` — tray icons at 16, 24, 32, 48 and 64 px
- `ico/` — Windows multi-resolution ICO files

## Notes
- SVG files are editable in Inkscape, Illustrator, Figma, or a text editor.
- Tray icons are provided in dark and light foreground variants. Test them against the actual desktop environment and tray API; some Linux desktop environments expect monochrome alpha-mask icons.
- This pack is an initial implementation based on the concept board, not a pixel-perfect extraction from the generated board image.
